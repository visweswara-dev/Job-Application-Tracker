# JobTrack – Job Application Tracker

JobTrack is a responsive web application designed to help job seekers organize and manage their job applications in one place.

## Features

- Add new job applications
- Track company names, job roles, locations and application dates
- Update application status
- Search applications by company or job role
- Filter applications by status
- Delete applications
- View dashboard statistics
- Automatically save data using browser Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start adding and managing job applications.
